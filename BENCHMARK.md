# AntFleet Benchmark — aeon

This repository is a public benchmark mirror used by [AntFleet](https://antfleet.dev) — a two-model PR review system that posts only findings both models agree on, with SHA-pinned receipts.

It is **not maintained** and **not affiliated** with the upstream project. The real project lives at [aaronjmars/aeon](https://github.com/aaronjmars/aeon) (MIT-licensed, by [@aaronjmars](https://github.com/aaronjmars)).

## What's benchmarked here

30 cherry-picked PRs from `aaronjmars/aeon` are replayed here as PRs against this fork's `main`. They cover four reviewer-stress categories:

| Category | Count | Purpose |
|---|---:|---|
| Security / hardening | 5 | Highest expected real-finding rate (shell-injection, workflow audit, skill scanner, gating) |
| Feature additions | 13 | Real product code across skills, dashboard, status page, CI — broad subsystem coverage |
| Chore / docs / CI | 5 | Calibration anchors — expected ≈0 findings; tests reviewers' false-positive rate |
| Cross-cutting fixes | 7 | Recurring patterns (`-R repo` arg series, alerting, digests) and mixed-subsystem changes |

The full shortlist with SHAs and expected-signal annotations lives in [antfleet/antfleet `.spike/venice-2026-05/pr-shortlist.json`](https://github.com/antfleet/antfleet) (private during the spike, published with the writeup).

Replay PRs in this fork are titled `<original title> (replay of <short-sha>)` and link to the upstream commit. None are intended for merge.

## How this works

1. Each benchmark target is a real `aaronjmars/aeon` commit (162 merged PRs + 1 closed-but-substantive PR available as of 2026-05-18).
2. The change is replayed as a PR on this mirror by cherry-picking the commit onto a branch from its parent.
3. AntFleet's GitHub App reviews the PR automatically: Anthropic `claude-opus-4-7` and OpenAI `gpt-5` run in parallel, and only unanimous findings post.
4. Receipts appear publicly on [antfleet.dev/receipts](https://antfleet.dev/receipts).
5. A separate research harness (`antfleet/antfleet:scripts/spike-per-pr.ts`) re-runs the same PRs with three additional open models (Qwen 3 Coder 480B, DeepSeek V4 Pro, Llama 3.3 70B) served via [Venice](https://venice.ai), to test whether open-model agreement adds real signal to the unanimous-agreement gate. Results are published in a follow-up writeup.

## Methodology

Each replay PR is generated by cherry-picking the upstream commit onto a branch from its parent, then opening a PR against this mirror's default branch. The resulting diff is identical to the upstream diff. AntFleet's review runs against that diff. Nothing is merged.

For PRs whose upstream commit is already in this fork's `main` (the fork was created mid-history), the replay branches off the upstream commit's parent — so the PR shows the original diff cleanly even though `main` already contains it.

## Why benchmark this repo

`aaronjmars/aeon` is an active open-source agent framework with substantive product code across skills, dashboard, CI, and security tooling. Its commit history spans a wide range of change types — exactly the variety needed to stress-test PR review across categories. The project is also already Venice-aware (its `#180` introduces VVVKernel/Venice skills), which makes it a natural fit for an open-model PR-review evaluation.

This is benchmark target #2 for AntFleet, after [antfleet/agent-autonomopoly-bench](https://github.com/antfleet/agent-autonomopoly-bench).

## Disclaimer

No upstream source files are copied or modified beyond the original commits being replayed. Every replayed PR cherry-picks an upstream commit and preserves original authorship metadata (commit author = original upstream author; committer = `antfleet-ops` for replay bookkeeping). This mirror exists for research and commentary purposes (PR review benchmarking).

To stop being benchmarked: open an issue on [antfleet/antfleet](https://github.com/antfleet/antfleet) and we will delete this mirror.
